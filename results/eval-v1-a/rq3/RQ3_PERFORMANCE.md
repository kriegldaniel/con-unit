## Methods

- Median and quartiles by linear interpolation between order statistics (type 7). IQR is Q3 minus Q1.
- Mean with a two-sided 95% confidence interval from Student's t distribution with n-1 degrees of freedom. The normal value 1.960 is used beyond 30 degrees of freedom. Standard deviation uses n-1.
- Tier 3 duration is bounded below by the probe window W by design. It is not a performance result.
- Cold trials follow an explicit image purge and include a registry transfer. They are network dependent and are reported apart from the warm local-store trials.
- Memory figures describe the ConUnit process only, never the container engine or probe containers. Peak RSS is reported once as a ceiling over the whole batch, not per image.
- ConUnit CPU time is the user plus system time of this process. Child CPU time covers the engine CLI and Syft. Both are reported only when the runner provides them.
- Tier 3 floor in seconds: (1 + N) x W, with N the number of Tier 3 treatments of the pack and W the probe window. It assumes that the baseline and the treatments run one after another, each container observed for the whole window: the runner evaluates the checks of a pack in order and one image after the other. An image whose containers stay running needs at least this long. An image whose baseline or a treatment exits earlier needs less. Treatments of this pack: EXEC-02, EXEC-07, EXEC-01, EXEC-04.
- Dockle comparison: after every warm-up and timed trial of ConUnit that succeeded, the same image is exported from the local store of the engine to a docker-archive (the export time) and Dockle is run on that archive with --format json (the analysis time), on the same host. The Dockle time of a trial is export plus analysis. Cold trials are not compared. Per image the median over its timed trials is taken, and the figures of the paper are the medians over images, in seconds.
